# FlowerKissTao

面向家庭植物用户的全栈植物服务应用：从环境匹配选购，到收货后的持续养护。

A full-stack app for choosing plants that fit your home and caring for them after delivery.

FlowerKissTao 将植物目录、环境画像、个性化推荐、购物流程（模拟支付）和养护计划放在同一条用户旅程中，并提供商品、知识、订单、用户和运营数据管理后台。

先阅读与你的语言对应的完整文档：

- [中文文档](./README.zh-CN.md)：环境准备、数据库初始化、开发启动、配置和 API 概览。
- [English documentation](./README.en.md)：prerequisites, database setup, local development, configuration, and API overview.
